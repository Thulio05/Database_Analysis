# Database Analysis

Este repositório contém diversos scripts e estudos de caso usando **MySQL**, com o objetivo de praticar consulta, modelagem e manipulação de dados em banco relacional.

---

## Sobre o Projeto

Os arquivos presentes são exercícios práticos de banco de dados, focados em desenvolvimento de queries SQL, criação de diferentes tipos de consultas e exploração de técnicas comuns de análise de dados.  
São usados para consolidar conhecimentos em agrupamentos, junções, filtros, subconsultas e entendimento de estrutura de dados dentro de um banco relacional.

---

## Ferramentas e Tecnologias Utilizadas

- **MySQL** — sistema de gerenciamento de banco de dados relacional  
- Editor SQL MySQL
- Conceitos explorados incluem: `SELECT`, `JOIN`, `GROUP BY`, `HAVING`, `WHERE`, `ORDER BY`, subqueries
